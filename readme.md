# ❤️ AI-Powered Health Risk Prediction System

An advanced AI-driven health monitoring and risk prediction platform built using **Python, Streamlit, Machine Learning, XGBoost, Isolation Forest and Agentic AI-inspired reasoning**.

This system intelligently analyzes:

* Heart Rate
* Sleep Duration
* Physical Activity
* Personalized Health Baselines

to generate:

* Health risk predictions
* Doctor-like AI insights
* Stress & recovery analysis
* Personalized wellness recommendations
* Interactive visual analytics

The project aims to simulate a real-world AI health companion rather than a traditional ML dashboard.

---
